# Text Purity — Plagiarism Detection System

Text Purity is an **offline-first plagiarism and AI-generated content detection platform**. It combines classic NLP techniques (TF-IDF, cosine similarity) with transformer-based models (Sentence-BERT, Hugging Face classifiers) to flag copied, paraphrased, and AI-written text — without ever sending documents to an external server.

Built for students, teachers, researchers, and professionals who need a private way to verify originality.
---

## ✨ Key Features

- 🔒 **Fully offline analysis** — documents never leave the local machine, ensuring data privacy.
- 📄 **Multi-format support** — plain text and PDF uploads.
- 🧠 **Plagiarism detection** — TF-IDF + cosine similarity to compare documents and highlight overlapping content.
- 🤖 **AI-content detection** — a fine-tuned classifier (Logistic Regression / SVM / BERT-based) flags text likely generated by tools like ChatGPT, Gemini, or Bard.
- 📊 **Detailed reports** — similarity percentage, flagged passages, and AI-confidence scores, exportable as PDF.
- ⚡ **Modern web stack** — React + Vite frontend talking to a FastAPI backend.
- 🗄️ **Lightweight storage** — SQLite for documents, batches, and comparison results (no external DB required).

## 🏗️ Architecture

```
Input (TXT / PDF)
      │
      ▼
Preprocessing  ──►  cleaning, tokenization, stopword removal, lemmatization
      │
      ▼
Feature Extraction ──► TF-IDF vectors / Sentence-BERT embeddings
      │
      ├──► Plagiarism Check (cosine similarity vs. reference/other uploaded docs)
      │
      └──► AI-Content Detection (classifier on embeddings)
      │
      ▼
Report Generation ──► similarity %, flagged sections, AI confidence
      │
      ▼
Web UI ──► upload, progress, results, PDF export
```

**Core modules:** Input handling → Preprocessing → Feature extraction → Plagiarism detection → AI-content detection → Reporting → UI.

## 🚀 Getting Started

### Prerequisites
- Python 3.12+
- Node.js & npm
- Git

### 1. Backend (FastAPI)

```bash
cd backend
venv\Scripts\activate        # Windows
# source venv/bin/activate   # macOS/Linux
pip install -r requirements.txt
uvicorn app.main:app --reload
```

Backend runs at: **http://127.0.0.1:8000**

### 2. Frontend (React)

Open a new terminal:

```bash
cd frontend
npm install
npm run dev
```

Frontend runs at: **http://localhost:5173**

> ⚠️ Both the backend and frontend must be running simultaneously.

## 🔍 How It Works

1. **Upload** — user submits one or more documents (TXT/PDF) via the web UI or API.
2. **Preprocessing** — text is cleaned, tokenized, stopwords removed, lemmatized.
3. **Feature extraction** — TF-IDF vectors and/or Sentence-BERT embeddings are generated.
4. **Plagiarism check** — cosine similarity compares documents within a batch (and/or against a reference set) to detect overlaps.
5. **AI detection** — a classifier estimates the probability that text is AI-generated vs. human-written.
6. **Report** — results are combined into a structured report (similarity %, flagged text, AI confidence) viewable in the UI or exportable as PDF.

### Example API endpoints

| Endpoint | Method | Description |
|---|---|---|
| `/dashboard` | GET | Summary of a user's batches and documents |
| `/documents/upload` | POST | Upload one or more files for analysis |
| `/batch/{batch_id}/results` | GET | Retrieve AI / plagiarism results for a batch |
| `/batches/{batch_id}/export/pdf` | GET | Export a batch's report as PDF |
| `/admin/stats` | GET | System-wide usage stats (admin only) |

## ⚠️ Current Limitations

- Text-only support at present — no direct image/OCR pipeline in production yet.
- Detection accuracy depends on dataset diversity; highly domain-specific or sophisticated paraphrasing can reduce accuracy.
- Large documents may be slow to process without GPU acceleration.
- AI-detection can misclassify short or heavily human-edited AI text.
